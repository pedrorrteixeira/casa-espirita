                Alterar cadastro

                  Telefone e e-mail não são exibidos: o sistema abre por um link sem senha, e mostrar aqui publicaria o contato dos frequentadores. Deixe em branco para manter o que está gravado, ou escreva um valor novo para substituir. Para ler o que está lá, use a planilha.

                  Desmarcar "ativo" impede novos empréstimos a esta pessoa, sem apagar nada. É como se afasta alguém que mudou de cidade ou está com pendência.

                  Este é o único lugar do sistema onde se muda o acesso de alguém — não precisa mais abrir a planilha. O sistema recusa tirar o acesso do último administrador ativo: promova outra pessoa antes.
